# World Simulator

クォータービューの村シミュレーション。
AI村人が自律的に行動するのを、プレイヤーは**神の視点**から観察し干渉する。

設計は [DESIGN.md](DESIGN.md) を参照。

## 前提：判断はAIが行う

キャラクターが何をするか、それをどう受け取るか、その結果自分の中の何が変わるかは、
すべてAIの担当で、**プログラムには一つも実装されていない**。

いま `Brain.choose()` は実行可能な行動からランダムに1つ返すだけ。
パラメータを読まないし、動かしもしない。AIを繋いだときにこの穴がそのまま埋まる。

> 「世界で何が起きたか」はプログラム。「それをどう受け取り、どうするか」はAI。

だから効用の式も、パラメータの駆動源も、出来事ごとの変化量も、派生特性も存在しない。
**材料表も無い。** 何をどれだけ使うか、いくつ取るかは、持ち物と目の前のものを見た本人が決める。

**量についてプログラムは何も見ない。** 上限はどこにも無い。
見ているのは、それが何であるかにまつわる3つだけ。

- **無いものは払えない** — 減らせるのは、持っているぶんまで
- **世界に無い物は生まれない** — 名前があるのは、神がこの世界に置いた物だけ
- **増えるのは、世界の物に触れているときか、作っているとき**
  （手の中のものを「使う」だけで増えるなら、「作る」という型が要らなくなる）

## パラメータ

**個人パラメータ**と**関係パラメータ**は構造が同じで、関わる人数だけが違う。

- **個人パラメータ** — 一人につき1つ（空腹、睡眠、退屈、孤独…）
- **関係パラメータ** — 相手1人につき1つ（好感、信頼、敬意、負い目…）。n人いれば n×n

定義が持つのは**名前だけ**。幅はスコープから決まり、束（カテゴリ）も語ごとの色も持たない。
値がどう動くかはAIが決めるので、定義側には何も要らない。

## アクション

**型 × 対象**で表す。定義の一覧は無い。

- 型：動く / 使う / 作る / 話す。この4つだけで、増やせない
- 対象：世界にある物と、神が決めたつくりかたから導かれる

**神が与えるのは名詞だけ。** 動詞は世界に元からある。
行動の名前もどこにも定義されていない——何をしているかは、そのつどAIが名づける。

**採るも作るも「手に入れる」**（型としては「作る」）。茂みで木の実を手に入れるのも、
木と石でハンマーを手に入れるのも、材料が空か、場所が要るかの違いしかない。
建てるも同じ型で、手に入るのではなく世界の上に建つという違いしかない。

「使う」に残るのは手の中のものと建物だけで、**使うでは何も増えない**。

| 何を使うか | 起きること |
|---|---|
| 手の中の持ち物 | 減る |
| 建物 | 何も減らない（置いていくなら減る）。何も手に入らない |

## 世界が寄越すもの

**何が、どこで、いくつで手に入るかは、手に入れかた（技術ツリー）に書いてある。**

- 手に入れかたが持つのは、材料（何をいくつ）と場所（茂み・木・岩か、建物）の2つだけ
- 1回の「手に入れる」で1つ手に入り、材料が書いてあるとおりに減る
- 茂み・木・岩は、木の実・木・石が手に入る場所。**世界の物は尽きない**
- 建物で手に入るものも、手に入れかたが建物を場所に指しているだけ（井戸で水、のように）

材料も場所も無いものは手に入らない（無から物は生まれない）。
物を持つことの代償は、材料と、そこまで歩く**場所と時間**。

歩きは手の中に畳んである。遠くの相手や場所でも、**見えていれば**候補に立ち、
選べば歩いていって、間合いに入ったところで行う。いつ選ぶかはAIが決める。

## つくりかた

作れるものと建てるものが持つのは、**名前と姿**と**手に入れかた**。「作る」の対象になる。

- 姿はあらかじめ用意された絵から選ぶ（道具・壺・布…／家・尖り屋根・倉・井戸・塔…）
- **手に入れかたを決めるのは神ではなく Jev。** 神が決めるのは名前と姿までで、
  木の実・木・石以外の手に入れかたは、世界が始まるときに Jev が1回で答える
- **建てたものは建てた人のもの**（屋根がその人の色になる）。家も、ただの建てるものの1つ
- ただし所有は事実であって権利ではない。**他人のものを使うのを世界は止めない**（使ってよいかは判断）
- **何軒建つかは決まっていない。** 見るのは置ける場所が空いているかだけ

## 「何をしているか」の名前

**行動の名前は世界のどこにも定義されていない。**
「教会」を使うのが祈るのか懺悔するのか、木の実を使うのが食べるのかかじるのかは、
そのつど本人（AI）が名づける。いまは判断がないので、
世界の言い方をそのまま短く言う（`木の実を使う` `木の実を手に入れる`）。

## プレイヤー（神）にできること

干渉は開始前と進行中で分かれる。

**開始前** — この世界の語彙と、そこに置く村人を決める。世界はまだ止まっている。

| できること | 場所 |
|---|---|
| ことばの追加 / 削除 / 改名 | 「ことば」 |
| つくりかた（作れるもの / 建てるもの）の追加 / 削除 / 改名、姿の変更 | 「つくりかた」 |
| 村人の追加 / 削除、名前・色・一言・性格4軸 | 「村人」 |
| 世界のルール（1日の長さ、夜になる時刻、歩く速さ） | 「世界」 |

タブはこの順（**語彙 → 物 → 人 → 流れかた**）。決める順そのもの。

「この世界を始める」を押すと村人が置かれ、時間が動き出す。

**進行中** — 定義もパラメータの値も変更できない。見るだけ。

| できること | 場所 |
|---|---|
| 個体の値・性格の閲覧 | 村人をクリック |
| n×n グリッドの閲覧 | 上部「関係」 |
| 差出人不明の貼り紙 | 上部「掲示板」 |
| 定義の閲覧（ことば / つくりかた / 村人 / 世界） | 上部「言葉」 |
| 村人一覧（誰がいま何をしているか） | 上部「村人」 |
| デバッグ（持ち物配布・建てるものを1つずつ建てる）※デバッグビルドだけ | 上部「デバッグ」 |
| この世界を終える（言葉のところへ戻る） | 上部「オプション」 |

始まった世界にできることは、見ることと、終えることだけ。
「オプション」から終えると「本当に終了しますか？」を訊いてから、
「設計図」へ戻る。島も記録も関係も持ち越さず、
決めた言葉と顔ぶれだけが残るので、書き足してまた始められる。

## 実行

```bash
mise exec -- godot --path .
```

ヘッドレスで観察する：

```bash
mise exec -- godot --headless --fixed-fps 60 --quit-after 40000 -- --echo-log --autostart
```

| 操作 | 動作 |
|---|---|
| 左クリック | 村人を選択 |
| 右 / 中ドラッグ | カメラ移動 |
| ホイール | ズーム |
| Space | 一時停止 |

## 構成

```
scripts/
  autoload/  schema(定義) / sim_config(世界のルール) / sim_clock / event_log
  data/      self_params / pair_params / personality / memory / rules
  world/     world / iso(クォータービュー変換) / harvest_node / structure(建物の姿) / bulletin_board
  villager/  villager(世界で何が起きたか) / brain(判断の置き場所。できることの列挙もここ)
  ui/        ui_kit / item_icon(世界の物の絵) / inspector / roster_panel
             matrix_panel(n×n) / rules_panel(設計図) / option_panel / hud
```

Godot 4.7.2 を `mise.toml` で固定。作業の経緯は [LOG.md](LOG.md)、
デザインレビューの観点と回し方は [REVIEW.md](REVIEW.md)。
