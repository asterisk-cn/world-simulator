# World Simulator

クォータービューの村シミュレーション。
AI村人が自律的に行動するのを、プレイヤーは**神の視点**から観察し干渉する。

設計は [DESIGN.md](DESIGN.md) を参照。

## 前提：判断はAIが行う

キャラクターが何をするか、それをどう受け取るか、その結果自分の中の何が変わるかは、
すべてAIの担当で、**プログラムには一つも実装されていない**。

いま `Brain.choose()` は実行可能な行動からランダムに1つ返すだけ。
パラメータを読まないし、動かしもしない。AIを繋いだときにこの穴がそのまま埋まる。

> 「世界で何が起きたか」はプログラム。「それをどう受け取り、どうするか」はAI。

だから効用の式も、パラメータの駆動源も、出来事ごとの変化量も、派生特性も存在しない。

## パラメータ

**個人パラメータ**と**関係パラメータ**は構造が同じで、関わる人数だけが違う。

- **個人パラメータ** — 一人につき1つ（空腹、睡眠、退屈、孤独…）
- **関係パラメータ** — 相手1人につき1つ（好感、信頼、敬意、負い目…）。n人いれば n×n

定義が持つのは 名前 / 範囲 だけ。カテゴリの中に足すので個別のカテゴリ欄はなく、色もカテゴリで決まる。
値がどう動くかはAIが決めるので、定義側には何も要らない。

## アクション

**タイプ × 対象**で表す。

- タイプ：動く / 採取 / 制作 / 建設 / 使用 / 交流
- 対象：タイプごとに選べるものが決まる（採取なら 木の実 / 木 / 石）

使用と交流は届く範囲にないと候補に出ない。遠ければ先に「動く」で近づく。
いつ選ぶかはAIが決める。

## プレイヤー（神）にできること

干渉は開始前と進行中で分かれる。

**開始前（セットアップ）** — この世界の語彙を決める。世界は止まっていて村人もいない。

| できること | 場所 |
|---|---|
| カテゴリとパラメータの追加 / 削除 / 改名、範囲の変更 | 設定「パラメータ」 |
| レシピの追加 / 削除 / 改名、材料の変更 | 設定「レシピ」 |
| アクションの追加 / 削除 / 改名 / タイプと対象の変更 | 設定「アクション」 |
| 世界のルール（1日の長さ、夜になる時刻、行動を選び直す間隔、移動速度、記憶の保持量） | 設定「世界」 |

「この世界を始める」を押すと村人が置かれ、時間が動き出す。

**進行中** — 定義もパラメータの値も変更できない。見るだけ。

| できること | 場所 |
|---|---|
| 個体の値・性格の閲覧 | 村人をクリック |
| n×n グリッドの閲覧 | 上部「関係マトリクス」 |
| 差出人不明の貼り紙 | 上部「掲示板」 |
| 設定の閲覧（パラメータ / アクション / レシピ / 世界） | 上部「設定」 |
| 村人一覧（誰がいま何をしているか） | 上部「村人」 |
| デバッグ（材料配布・家を建てる） | 上部「デバッグ」 |

## 実行

```bash
mise exec -- godot --path .
```

ヘッドレスで観察する：

```bash
mise exec -- godot --headless --fixed-fps 60 --quit-after 40000 -- --echo-log --autostart
```

| 操作 | 動作 |
|---|---|
| 左クリック | 村人を選択 |
| 右 / 中ドラッグ | カメラ移動 |
| ホイール | ズーム |
| Space | 一時停止 |

## 構成

```
scripts/
  autoload/  schema(定義) / sim_config(世界のルール) / sim_clock / event_log
  data/      self_params / pair_params / personality / memory / rules
  world/     world / iso(クォータービュー変換) / harvest_node / structure / bulletin_board
  villager/  villager(世界で何が起きたか) / brain(判断の置き場所)
  ui/        ui_kit / range_slider / inspector / roster_panel / matrix_panel(n×n) / rules_panel(設定) / debug_panel / hud
```

Godot 4.7.2 を `mise.toml` で固定。作業の経緯は [LOG.md](LOG.md)。
