# 流れのシナリオ

最初の顔ぶれと、夜ごとに書き足す言葉・人をファイルに書いておき、村を何日か通しで動かして、
Jev が何を選び、値をどう答えたかを日ごとに数える（`scripts/tools/flow_run.gd`）。

```
godot --headless --path . -- --flow=01 [--days=N] [--speed=1] [--seed=N] [--with-text] [--judge]
```

- `--flow=01` … ファイル名がこれで始まるもの（1本に絞れる頭を書く）
- `--days=N` … `終わり.日` の代わりに、N日目まで
- `--speed=` … 村の時間の速さ
- `--seed=N` … 書かなかった性格・気質と、村人を置く場所を揃える（Jev の答えは揃わない）
- `--with-text` … 文章の相手（作者の財布から出るほう）も使う。既定は止める
- `--judge` … `期待` に失敗が1つでもあれば終わりのコードを1にする（`--check` が使う）

画面ありで動かす（`--headless` を付けない）と、同じ流れを見ながら動かせる。
夜の書き足しは紙を開かずに入る。

結果は標準出力と `user://jev_bench/flow-*.md`（.json が答えそのもの）。
日ごとの表、期待の判定、Jev が組んだ手に入れかた、流れのファイルそのものを載せる。

## 書き方

```json
{
  "名前": "…",
  "ねらい": "…",
  "目盛り": {"1日の長さ": 60, "夜になる時刻": 20, "歩く速さ": 1},
  "はじめ": {
    "じぶん": ["空腹", "孤独"],
    "あいて": ["好感", "信頼"],
    "もちもの": ["ハンマー", {"名前": "パン", "姿": "焼いたもの"}],
    "たてもの": ["家"],
    "村人": [{"名前": "ハル", "性格": "働き者", "気質": ["外向", "感情"]}, "ミナ"]
  },
  "夜": {
    "1": {"じぶん": ["嫉妬"]},
    "2": {"村人": [{"名前": "ノア"}]}
  },
  "終わり": {"日": 3},
  "期待": [ … ]
}
```

| 欄 | 中身 |
|---|---|
| `目盛り` | 設計図の「詳細」と同じ名前で。書かなければ既定のまま |
| `はじめ` | 最初の紙に書くもの。じぶん・あいて・もちもの・たてもの・村人 |
| `夜` | 「N日目の夜」に書き足すもの。中身は `はじめ` と同じ形。書いていない夜は何も足さずに朝へ進む |
| `終わり.日` | この日が終わったら止める。数えるのは村の中の日（実時間の秒ではない） |
| `期待` | 下の表 |

- **もちもの・たてもの**は名前だけか、`{"名前", "姿"}`。姿は設計図に並ぶ名前（道具・刃物・壺・焼いたもの・布・縄・飾り・あかり／家・尖り屋根・広間・倉・井戸・塔）。
  木の実・木・石は島にはじめから在るので書かなくてよい（書いても足さない）
- **手に入れかたは毎回 Jev が組む**（ゲームと同じ、`world/tech_tree.gd`）。何になったかは表の終わりに載る
- **村人**は名前だけか、単発シナリオの `あなた` と同じ形（`名前`・`性格`・`気質`）。
  書かなかったところは振る（`--seed` で揃う）。気質は書いた語の側、書かなかった軸は反対側
- この世界に無い目盛り・姿、同じ名前が2つ、12人を超える村人、終わりより後の夜は、**始める前に止める**

夜の書き足しは、夜の紙で「続ける」を押したのと同じ順で入る（`main.night_quiet`）：
書き足した物の手に入れかたを Jev に訊く → 書き足した人を置いて考えさせる → 固める → 時間を動かす。

## 期待

単発シナリオと同じ書き方（`bench/scenarios/README.md`）に、日と村人で絞るのと、流れだけの3つが足される。

| 書き方 | 何を見るか | 外したとき |
|---|---|---|
| `"日": "3"` `"2-"` `"-2"` `"2-4"` | その日の答えだけで数える（書かなければ全部の日） | |
| `"村人": "ハル"` | その人の答えだけで数える | |
| `{"答えに出る": "嫉妬"}` | その言葉が問いに出て、答えが返った | 失敗 |
| `{"村人": "ノア", "考えた": ">=1"}` | その人が考えた（Jev の答えが返った）回数 | 失敗 |
| `{"一覧に出る": "パン"}` | 手の一覧に、その名前を含む手が出た。払える手しか出ないので村の様子による | 警告 |
| `{"手に入れかた": "パン"}` | 終わったときに、その物の手に入れかたが組まれている | 失敗 |

流れでは、値の**動き**は自分の言葉だけ測れる（答える前と後の値の差の平均）。相手への言葉は段階だけ。

## 既定の流れ

| ファイル | 何を確かめるか |
|---|---|
| `01_言葉と人を足す` | 1日目の夜に足した「嫉妬」が2日目から答えに出るか。2日目の夜に来たノアが3日目に考えるか |
| `02_物と建物を足す` | 1日目の夜に足したパンと井戸に手に入れかたが組まれ、2日目から手の一覧に出るか |
